# 시안 F 브리프 — 청첩장 × 둘의 투어 다이어리

## 지금까지의 피드백
- D: 색이 별로, 어디서 본 듯함, 고급스럽지 않음
- E1/E2(매거진): **"왜 이렇게 양산형 같지?"**
  - 원인: Unsplash + Pretendard + 명조 제목 + 섹션 번호·얇은 선 같은 흔한 조합, 브랜드 성격 없음, "헤더 + 카드 + 하단 탭 5개" 틀이 모든 시안에서 같았음
- 사용자가 고른 콘셉트: **청첩장 + 둘의 투어 다이어리가 잘 조화된 것**

## 콘셉트
> 우리 둘이 함께 채워 가는 결혼 준비 기록장. 겉은 잘 만든 청첩장처럼 격식 있고, 안은 둘이 쓰는 투어 다이어리처럼 손맛이 있다.

### 청첩장 쪽 (격식·고급)
- 종이 질감 바탕(SVG noise 필터나 아주 옅은 섬유 질감, 이미지 파일 없이 CSS/SVG로). 완전 흰색 말고 질 좋은 종이 톤.
- 활판 인쇄(letterpress)처럼 살짝 눌린 느낌의 한글 명조 제목(예: Song Myung, Nanum Myeongjo, Gowun Batang 중 고르되 E1/E2가 쓴 Hahmlet은 피한다).
- 견적은 청첩장 속지 같은 **"견적 명세서"**: 인쇄된 표처럼 정돈, 점선 리더(항목 ...... 금액), 작은 장식 괘선.
- 은은한 실링 왁스, 리본, 봉투 같은 소품은 **한두 개만** 절제해서. 과하면 촌스럽다.

### 다이어리 쪽 (둘이 같이·손맛)
- 웨딩홀 사진은 **폴라로이드** 프레임(아래가 두꺼운 흰 테두리), 살짝 기울여서(−3°~3°) 마스킹테이프로 붙인 듯.
- 폴라로이드 아래·옆에 **민지와 준호의 손글씨 메모**(각자 다른 손글씨 폰트, 다른 잉크색). 예: 민지 "샹들리에 진짜 예뻤어 ★4", 준호 "주차 불편… 그래도 ★5". 손글씨 폰트는 Google Fonts의 한글 손글씨(Nanum Pen Script, Gaegu, Gamja Flower, Hi Melody 등) 중 두 개.
- 손글씨는 **메모와 감정에만**. 숫자·금액은 절대 손글씨로 쓰지 않는다(정확해 보여야 함).

### 이 앱만의 장면 (시그니처)
- **폴라로이드를 누르면 뒤집혀서(3D flip) 뒷면에 그 홀의 견적 메모**: 1인당 식대, 대관료, 보증 인원, 하객 200명 기준 총비용, 강남 중간값 대비. 앞면은 설렘(사진), 뒷면은 현실(숫자). reduced-motion이면 뒤집기 대신 크로스페이드.
- 시안에서는 한 장은 뒤집힌 상태로 보여 준다.

### 틀
- "헤더 + 둥근 카드 반복 + 하단 아이콘 탭 5개" 틀을 쓰지 않는다.
- 내비게이션은 **다이어리 옆면 색인 탭**(종이 탭이 오른쪽 가장자리나 아래에 튀어나온 형태: 견적 · 일정 · 비용 · 청첩장)처럼. 모바일 엄지 닿는 위치는 지킨다(44px).
- 페이지는 다이어리를 넘기는 느낌(종이 한 장 = 한 섹션).

## 내용 (d-photo.html과 같은 숫자)
- 첫 장: 청첩장 표지처럼 "민지 그리고 준호 / 2027. 4. 10. 토요일 / D-127 / 서울 강남". 그 아래 결론 한 문장: "스드메 견적이 강남 평균보다 약 54만 원 높아요" + 가장 큰 위험 "라온홀 보증 인원 때문에 4,750,000원을 더 낼 수 있어요".
- 투어 다이어리: 홀 5곳 폴라로이드(사진·이름·투어 날짜·둘의 손글씨 메모·비교 체크). 최대 5곳 비교.
- 5곳 비교: 청첩장 속지 같은 인쇄 표. 총비용 낮은 순(가든 루체 22,880,000 / 포레 웨딩 23,000,000 / 채플 드 메이 26,100,000 / 더 리안 28,800,000 / 라온홀 30,750,000), 1위와 차이. 모바일에서 넘치면 순위 요약을 먼저, 상세는 가로 스크롤.
- 스드메 견적 명세서: 스튜디오 1,800,000 (중간값 1,530,000, +18%), 드레스 2,100,000 (1,780,000, +18%), 메이크업 950,000 (1,000,000, 비슷함).
- 숨은 추가금: 원본 데이터 약 22만 / 헬퍼비 약 25만 / 얼리스타트 약 10만 — "확인 전". 추가금까지 최대 5,420,000원.
- 출처: 한국소비자원 참가격 2026년 9월 조사, 지역 중간값. 참고용.

## 기술·품질
- 파일 하나(`f-invitation-diary.html`), 모바일 390px, 라이트 모드, AA 대비, 44px 터치, 숫자 tabular-nums.
- 사진은 d-photo.html의 Unsplash 사진 재사용(출처 주석 유지).
- 피할 것: AI 기본값(크림+테라코타, 모두 대문자 라벨, 이모지 아이콘), 자두·보라, 칩·배지 남발, 과한 소품.
