# 시안 공통 브리프

세 시안 모두 **같은 화면, 같은 내용**을 다른 디자인 방식으로 만든다. 비교 대상은 디자인뿐이다.

## 서비스
- 예비부부가 함께 쓰는 결혼 준비 앱. 웨딩 견적을 지역 평균과 비교하고, 일정·체크리스트, 결혼 비용 관리, 모바일 청첩장까지 둘이 같이 관리한다. 업체 광고가 아니라 커플 편에 선다.
- 이름 미정. 화면에는 `가칭` 로고 자리만 둔다.
- 사용자: 20대 후반~30대 초반 예비부부. 주로 휴대폰으로 본다.
- 라이트 모드 전용. 따뜻하지만 광고처럼 들뜨지 않고, 숫자를 믿을 수 있어 보여야 한다.

## 화면: "내 견적 비교" (모바일 390px 기준, 데스크톱에서도 가운데 정렬로 자연스럽게)
1. 상단: 로고 자리(가칭), 커플 표시(민지 · 준호), 예식 D-127 (2027.04.10), 지역 "서울 강남"
2. 요약: "내 견적이 평균보다 **약 54만 원** 높아요"(4,850,000 − 4,310,000) 같은 한 문장 요약 (스드메 합계 기준)
3. 스드메 비교 (내 견적 vs 서울 강남 중간값)
   - 스튜디오: 1,800,000원 vs 1,530,000원 → +27만 원 (+18%, 높음)
   - 드레스: 2,100,000원 vs 1,780,000원 → +32만 원 (+18%, 높음)
   - 메이크업: 950,000원 vs 1,000,000원 → -5만 원 (비슷함)
4. 숨은 추가금: 견적에 포함 여부를 확인하지 않은 항목
   - 스튜디오 원본 데이터 (보통 약 22만 원) — 확인 필요
   - 드레스 헬퍼비 (보통 약 25만 원) — 확인 필요
   - 메이크업 얼리스타트 (보통 약 10만 원) — 확인 필요
   - "추가금까지 넣으면 최대 **5,420,000원**" (스드메 견적 합계 4,850,000 + 570,000)
5. 웨딩홀 (하객 200명 예상)
   - 1인당 식대 95,000원 vs 88,000원 (+8%)
   - 대관료 7,000,000원 vs 7,500,000원 (-7%)
   - 보증 인원 250명 → 하객이 50명 적어서 **4,750,000원**을 더 냄 (경고)
6. 출처 한 줄: "한국소비자원 참가격 2026년 9월 조사, 지역 중간값 기준. 참고용입니다."
7. 하단 탭: 홈 · 견적 · 일정 · 비용 · 청첩장 (견적 선택됨)

## 기술 조건
- 파일 하나로 된 정적 HTML (CSS 포함). 외부 리소스는 한글 웹폰트 CDN(예: Pretendard, jsdelivr) 정도만.
- 실제 앱 화면처럼 보이게. 와이어프레임이 아니라 완성 시안.
- 글자 대비 WCAG AA 이상, 터치 영역 44px 이상.
- 금액은 tabular-nums, 원 단위 콤마.
