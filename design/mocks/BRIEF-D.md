# 시안 D 브리프 — 사진이 있는 견적 비교

BRIEF.md의 서비스 설명·내용·기술 조건을 그대로 따르되, 아래를 바꾼다.

## 사용자 피드백 (가장 중요)
- 견적 비교 방식은 좋다. 그런데 **텍스트만 있어서 보는 맛이 없다. 웨딩홀 사진은 무조건 있어야 한다.**

## 방향
- **정보 순서는 시안 C**: 결론 한 문장 → 가장 큰 위험 경고 → 항목별 비교 → 숨은 추가금 → 웨딩홀.
- **숫자 표현은 시안 B**: 중간값 눈금 위 점(또는 C의 막대+눈금 중 더 읽기 쉬운 쪽), 추가금 최대액은 진한 박스로 강하게.
- **사진이 화면의 주인공 중 하나**가 되게. 숫자 화면에 사진을 장식으로 붙이는 게 아니라, 사진을 보고 고르고 숫자로 확인하는 흐름.

## 바뀐 내용
1. 상단에 이번에 투어한 웨딩홀들의 **사진 카드 가로 스크롤**(3곳). 카드마다:
   - 큰 사진(4:3 또는 3:4), 홀 이름, 투어 날짜, 둘의 하트/별점(민지 ★4, 준호 ★5 같은 각자 평가)
   - 핵심 숫자 한 줄: 1인당 식대, 평균 대비 칩(높음/비슷함/낮음)
   - 사진 위에 "사진 12장" 같은 개수 배지
   - 홀 예시
     - 라움 아트센터: 식대 95,000원(+8%), 대관료 7,000,000원(−7%), 보증 250명
     - 더채플앳청담: 식대 88,000원(비슷함), 대관료 8,500,000원(+13%), 보증 200명
     - 루벨 강남: 식대 79,000원(−10%), 대관료 5,500,000원(−27%), 보증 220명
   - 홀 이름은 실제 업체를 흉내 내지 않도록 가상의 이름으로 바꿔도 된다(예: "라온홀", "채플 드 메이", "가든 루체").
2. 선택된 홀(첫 번째)의 상세 비교: 식대·대관료·보증 인원 경고(하객 200명 → 4,750,000원 더 냄).
3. 스드메 섹션에도 업체 대표 사진 썸네일(정사각형 작은 사진)을 항목 옆에 넣는다(스튜디오 촬영 사진, 드레스, 메이크업).
4. 빈 상태 힌트: "투어 때 찍은 사진을 올리면 둘이 같이 비교할 수 있어요" 같은 사진 추가 버튼(카드 맨 끝).

## 추가 피드백: 홀끼리 비교
- 지역 평균 비교도 좋지만, **내가 해보고 싶은 홀 여러 개를 골라서 서로 비교**하는 기능이 있어야 한다.
- 사진 카드마다 선택 체크(**최대 5곳**. 3곳은 부족하다는 피드백). 2곳 이상 고르면 하단에 "N곳 비교하기" 버튼이 떠오른다.
- 휴대폰에서 5곳을 다 보이게: 항목 이름 칸은 왼쪽에 고정(sticky)하고 홀 열은 가로로 넘겨 보는 표. 표 위에 "하객 200명 기준 총비용 낮은 순" 순위 요약(사진 썸네일 + 금액 + 1위와의 차이)을 둬서 넘기지 않아도 결론이 보이게.
- 투어 홀은 5곳. 추가 2곳: 더 리안(식대 99,000원 +13%, 대관료 9,000,000원 +20%, 보증 200명 → 총 28,800,000원), 포레 웨딩(식대 85,000원 비슷함, 대관료 6,000,000원 −20%, 보증 180명 → 하객 200명이라 보증 초과 없음 → 총 23,000,000원).
- 시안에서는 5곳이 모두 선택된 상태로 비교 화면을 보여 준다. 총비용 순위: 가든 루체 22,880,000 < 포레 웨딩 23,000,000 < 채플 드 메이 26,100,000 < 더 리안 28,800,000 < 라온홀 30,750,000.
- 비교 화면(같은 파일 안의 섹션이나 바텀시트로 표현): 홀별 대표 사진을 맨 위에 나란히, 그 아래 행마다 1인당 식대, 대관료, 보증 인원, 하객 200명 기준 총비용, 지역 평균 대비, 둘의 평가를 비교. 항목별로 가장 유리한 값에 표시(예: "가장 저렴").
- 하객 200명 기준 총비용: 라온홀 = 95,000×250(보증)+7,000,000 = 30,750,000원 / 채플 드 메이 = 88,000×200+8,500,000 = 26,100,000원 / 가든 루체 = 79,000×220(보증)+5,500,000 = 22,880,000원.

## 사진
- **대표 사진으로 정당하게 쓸 수 있는 사진만** 쓴다. 실제 업체 홈페이지·블로그 사진은 저작권 때문에 쓰지 않는다. 시안은 Unsplash(무료 상업 사용 가능 라이선스)만 쓴다. 실제 서비스에서는 커플이 직접 찍은 투어 사진, 또는 업체가 직접 등록·허락한 사진만 쓴다.
- 시안용으로 Unsplash의 실제 사진 URL을 쓴다(images.unsplash.com, 무료 사용 가능). 브라우저로 unsplash.com에서 "wedding venue", "wedding hall", "wedding chapel", "wedding dress", "bridal makeup", "wedding photography" 등을 검색해 **실제로 열리는** 사진 주소를 골라 쓴다. 주소가 깨지면 안 된다(렌더링해서 확인).
- `?w=800&q=80&auto=format&fit=crop` 같은 파라미터로 크기를 줄인다.
- 사진 위 글자는 대비가 확보되게(그라데이션 오버레이 등).
- HTML 주석에 사진 출처(Unsplash 사진 페이지 URL)를 남긴다.
