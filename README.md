# AI 기반 웨딩 플래닝 및 견적 비교 플랫폼

> **한 줄 요약**: 업체 말고 커플 편에 서는 결혼 준비 계산기. 공개된 지역 평균 가격을 기준으로 상담 견적이 적정한지와 숨은 추가금까지 미리 알려 줍니다.

---

## 💍 프로젝트 개요
웨딩 업체, 특히 스드메는 가격을 미리 공개하지 않아 상담에 가야 견적을 알 수 있고, 계약 직전이나 뒤에 추가금이 붙습니다. 이 서비스는 업체 협조나 다른 사용자의 견적 공유 없이, 지역 평균 가격을 기준으로 커플이 받은 견적을 비교할 수 있게 합니다. 직접 상담한 견적이든 중개업체 패키지든, 계약 전에 한 번 확인하는 곳이 되는 것이 목표입니다.

자세한 기획은 [docs/PLAN.md](docs/PLAN.md)를 참고하세요.

## ✨ 주요 기능 (MVP)
첫 업종은 **스드메**(스튜디오, 드레스, 메이크업)와 **웨딩홀**입니다.

1. **지역별 평균**: 지역을 고르면 스드메 항목별, 웨딩홀 1인당 식대·대관료의 중간값과 전국 평균을 보여 줍니다.
2. **상담 견적 비교**: 상담에서 받은 견적을 입력하면 지역 평균 대비 항목별 차이를 업체끼리 나란히 비교합니다.
3. **웨딩홀 비교**: 예상 하객 수로 홀별 총비용을 계산하고, 1인당 식대와 대관료를 지역 평균과 비교합니다.
4. **숨은 추가금 예측**: 자주 붙는 추가금 중 견적에 빠진 항목을 알려 주고, 추가금까지 넣은 예상 최종 금액을 보여 줍니다.
5. **날짜별 비용 차이**: 예식 시기에 따른 평균 비용 차이와 예상 절약액을 보여 줍니다.
6. **AI 일정·체크리스트**: 결혼 예정일 기준으로 할 일과 마감일을 만듭니다.
7. **커플 공유**: 두 사람이 같은 데이터를 함께 보고 수정합니다.

## 🗺 로드맵

- **Database / Auth**: Supabase
- **AI**: LLM API (체크리스트 생성, 계약서 점검)
- **Deploy**: Vercel
