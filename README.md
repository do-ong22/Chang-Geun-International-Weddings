# AI 기반 웨딩 플래닝 및 견적 비교 플랫폼

> **한 줄 요약**: 광고 중심 웨딩 플랫폼이 아닌, 실제 결혼 준비를 도와주는 AI 기반 견적 비교 및 플래닝 서비스

---

## 💍 프로젝트 개요
기존 웨딩 플랫폼의 광고 중심 구조에서 벗어나, 실제 사용자가 결혼 준비 과정에서 겪는 정보 비대칭과 비효율성을 해결하는 플랫폼입니다. 사용자의 예산과 스타일에 맞춘 업체 견적 비교 및 AI 기반의 자동화된 플래닝 기능을 제공합니다.

## ✨ 주요 기능
1. **견적 비교 시스템 (헤이딜러 방식)**
   - 사용자가 조건 입력 시 다수의 업체로부터 견적을 제안받아 비교 분석.
2. **AI 기반 웨딩 플래닝 자동화**
   - 결혼 준비 일정 자동 생성 및 맞춤형 체크리스트 제공.
   - 준비 가이드 및 템플릿 추천.
3. **신뢰할 수 있는 후기 시스템**
   - 광고성 리뷰를 배제한 실사용자 중심의 검증된 리뷰 데이터 구축.
4. **실시간 정보 및 트렌드 제공**
   - 마감 임박 웨딩홀, 박람회 이벤트 및 최신 웨딩 트렌드 정보 제공.
